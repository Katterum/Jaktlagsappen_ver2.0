# Jaktlaget 2.0.0

Bygger vidare pa den stabila 1.9.3-basen.

Nytt i 2.0.0:
- Jaktdag med dagens passfordelning, observationer och fallt vilt.
- Observationer 2.0 med periodfilter, trend, artstatistik och kartbaserad tathetsvy.
- Matverktyg under Mer for avstand och areal i hektar.
- Sparade omraden med namn och beraknad areal.
- Arsrapport med utskrift eller Spara som PDF.

Befintlig funktionalitet for pass, hundforarvagar, vind, statistik, historik och backup ar bevarad.
